# Bitcoin Core icon

`bitcoin-core.svg` is the unmodified official Qt icon source from Bitcoin Core
v32.0rc2, `src/qt/res/src/bitcoin.svg`:
https://github.com/bitcoin/bitcoin/blob/v32.0rc2/src/qt/res/src/bitcoin.svg

Upstream Git blob: `14cf0c5e115f239e535b06043966db7d5a4761cd`.
The accompanying `BITCOIN-COPYING` is the upstream MIT license.
The installer copies this local asset; it does not fetch an icon after hardening.
